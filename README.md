# RFID-ExSim 데이터 자율탐구 프로젝트

2026 SIMs 1학년 데이터 기반 자율탐구를 위한 **RFID-ExSim 데이터셋 분석·시각화 노트북**입니다.

| 파일 | 내용 |
|---|---|
| `rfid_analysis.ipynb` | 자율탐구 로드맵 순서로 짠 Colab 노트북 (S1~S5 전체 탐색 → S1+S5 깊게 분석) |
| `데이터셋_설명.md` | 데이터셋을 고1 수준으로 쉽게 풀어 쓴 설명 (개념, 시나리오, 열 의미, 폴더 구조, 주의점) |

## 1. 데이터 받기
원본: <https://github.com/yasserhmimou9/RFID-ExSim-Dataset/tree/v1.0> (MIT License)

GitHub 저장소에는 설명서만 있고, **실제 데이터는 그 README의 OneDrive 링크**에서 zip으로 내려받습니다. (약 6MB)

## 2. Colab에서 실행하기
1. <https://colab.research.google.com> → `파일 > 노트북 업로드` → `rfid_analysis.ipynb`
2. `런타임 > 모두 실행`
3. 파일 선택 창이 뜨면 내려받은 `RFID-ExSim-dataset.zip`을 고릅니다. 압축은 노트북이 알아서 풉니다.
4. ✏️ 표시 칸(탐색 기록)을 더블클릭해서 모둠이 직접 채웁니다.
5. 마지막 셀을 실행하면 그래프 10장이 `rfid_figures.zip`으로 내려받아집니다.

## 3. 노트북 구성

| 파트 | 로드맵 | 내용 | 보고서 칸 |
|---|---|---|---|
| 1 | ② 데이터 이해 | S1~S5 요약표, 열별 결측 비율, 이 데이터로 알 수 없는 것 | Ⅱ-1, Ⅱ-2 |
| 2 | ③ 여러 방향 탐색 | 공통 비교(시나리오 × 거리·각도별 성공률), 시나리오별 그래프 1개씩 | Ⅱ-4, Ⅲ-1, Ⅲ-2 |
| 3 | ④ 패턴 고르기 · ⑤ 질문 | 거리·각도에 따라 성공률이 달라지는 폭을 시나리오별로 비교 | Ⅲ-4, Ⅳ-4 |
| 4 | ⑦ 가설 · ⑧ 의심하기 | S1 성공률 점검, S5 실험 계획표와 요청 속도, 같은 속도끼리 각도 비교, 수집 방식 의심 | Ⅲ-3, Ⅳ-3 |
| 5 | ⑦ ⑧ ⑨ 정리 | 가설·근거 표·대안 설명·다음 검증 계획 작성 칸 | Ⅴ-1~4 |
