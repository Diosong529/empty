# RFID-ExSim 데이터 자료집

2026 SIMs 1학년 데이터 기반 자율탐구용 **RFID-ExSim 데이터셋 설명 · 기초 분석 · 시각화 자료**입니다.
해석이나 결론은 넣지 않았습니다. 무엇이 흥미로운지, 무엇을 더 파고들지는 학생이 직접 판단합니다.

| 파일 | 내용 |
|---|---|
| `데이터셋_설명.md` | 데이터셋을 고1 수준으로 풀어 쓴 설명 (RFID 개념, 시나리오 S1~S5, 열의 의미, 폴더 구조) |
| `RFID_자료집.ipynb` | S1~S5를 같은 형식으로 정리한 기초 분석과 그래프 (실행 결과 포함, GitHub에서 바로 볼 수 있음) |
| `자료집_그래프/` | 자료집의 그래프 14장 (PNG, 보고서에 바로 사용 가능) |

## 자료집 구성
| 순서 | 내용 |
|---|---|
| 1. 전체 개요 | 시나리오별 기록 수·세션 수·리더기·기록 종류·거리·각도, 열별 결측 비율, 파일 목록 |
| 2. 시나리오 비교 | 거리·각도별 성공률(5개 시나리오 나란히), 시나리오별 기록 간격 |
| 3~7. 시나리오별 (S1~S5) | 같은 순서로: 실험 설명 → 기록 요약 → 기록 예시 → 실험 계획표 요약 → 기록 간격 분포 → 시나리오별 요약 파일과 그래프 |

## 데이터 받기 · 직접 실행하기
1. 원본 <https://github.com/yasserhmimou9/RFID-ExSim-Dataset/tree/v1.0> (MIT License)의 README에 있는 OneDrive 링크에서 zip(약 6MB)을 받습니다.
2. <https://colab.research.google.com> → `파일 > 노트북 업로드` → `RFID_자료집.ipynb`
3. `런타임 > 모두 실행` → 파일 선택 창에서 zip 선택 (압축은 자동으로 풀림)
4. 코드의 시나리오 이름, 세션 이름(`SID`), 열 이름을 바꿔 가며 직접 더 탐색할 수 있습니다.
