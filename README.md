# 1부. 데이터 알아보기

## 1. RFID가 뭔가요?

**전파로 카드를 알아보는 기술**입니다. 교통카드, 학생증, 아파트 출입카드가 모두 RFID예요.

- **태그(카드)**: 고유 번호(**UID**)가 들어 있는 카드. 배터리 없이 리더기의 전파로 작동해요.
- **리더기**: 전파를 보내 카드를 읽는 장치. 개찰구의 "삑" 하는 부분이에요.

이 실험에서는 작은 컴퓨터 보드(**ESP32**)에 RFID 모듈(**MFRC522**)을 연결해 리더기 2대(`ESP32_A`, `ESP32_B`)를 만들고,
카드 12장(`TAG01` ~ `TAG12`)을 사용했어요.

## 2. 다섯 가지 실험

| 실험 | 무엇을 했나요? | 기록 수 |
|---|---|---|
| **S1 정상** | 카드를 거리와 각도를 바꿔 가며 평범하게 찍음 | 13,004 |
| **S2 동시 읽기** | 리더기 2대가 카드 한 장을 동시에 읽음 | 31,776 |
| **S3 복제** | 번호(UID)가 같은 카드 두 장을 함께 둠 | 32,400 |
| **S4 재전송** | 이미 읽힌 카드 번호를 복제 카드·휴대폰·프로그램으로 다시 보냄 | 41,719 |
| **S5 폭주** | 아주 짧은 시간에 읽기 시도를 수천 번 몰아서 함 | 289,523 |

**실험 조건**

| 실험 | 실험 횟수(세션) | 거리 | 각도 |
|---|---|---|---|
| S1 | 108번 | 1, 3, 4cm | 0°, 45°, 90° |
| S2 | 108번 | 1, 3, 4cm | 0°, 45°, 90° |
| S3 | 108번 | 1, 2, 3cm | 0°, 45°, 90° |
| S4 | 36번 | 1, 2, 3cm | 0°, 45°, 90° |
| S5 | 36번 | 1, 2, 3cm | 0°, 45°, 90° |

> 💡 **세션**은 "실험 1회"를 말해요. 예를 들어 "TAG01 카드를 1cm, 0°로 읽은 실험"이 세션 하나예요.
> S5는 거리·각도가 기록 파일에는 없고 **실험 계획표**에만 적혀 있어요.

## 3. 기록 한 줄 읽는 법

데이터는 **한 줄에 기록 1건**씩 저장되어 있어요. 아래는 S1의 첫 줄이에요.

```
시각: 2025-11-04 08:12:55.469573 (세계 표준시)
실험: S1, 세션 S20251104_S1_TAG01_d1_o0_run1
리더기: ESP32_B    카드: TAG01    거리: 1cm    각도: 0°
결과: read_success (읽기 성공)
```

→ "11월 4일 8시 12분 55초에, 리더기 B가 TAG01 카드를 1cm·0°로 읽는 데 성공했다."

**자주 쓰는 열(항목)**

| 열 이름 | 뜻 | 예 |
|---|---|---|
| `timestamp_iso` | 기록된 시각 | 2025-11-04T08:12:55.469573Z |
| `session_id` | 어느 실험(세션)인지 | S20251104_S1_TAG01_d1_o0_run1 |
| `scenario` | 어느 실험 종류인지 | S1 ~ S5 |
| `device_id` | 어느 리더기인지 | ESP32_A, ESP32_B |
| `tag_local_id` | 어느 카드인지 | TAG01 ~ TAG12 |
| `distance_cm` | 카드와 리더기 사이 거리 (cm) | 1, 2, 3, 4 |
| `orientation_deg` | 카드를 기울인 각도 (°) | 0, 45, 90 |
| `event` | 기록 종류 | 아래 표 참고 |

**기록 종류(`event`)**

| 값 | 뜻 | 나오는 실험 |
|---|---|---|
| `read_success` | 읽기 성공 | 전부 |
| `read_fail` | 읽기 실패 | S4 |
| `read_injected` | 프로그램이 끼워 넣은 기록 | S4 |
| `raw` | 리더기가 켜질 때 나오는 메시지 | S1 |

# 2부. 분석 방법

`RFID_자료집.ipynb`에서 한 작업을 순서대로 정리했어요.
**Google Colab**에서 **Python**(pandas, matplotlib)으로 분석했어요.

## 1단계. 불러오기와 정리

1. S1~S5 기록 파일 5개를 각각 표로 불러왔어요.
2. 시각(`timestamp_iso`)을 컴퓨터가 계산할 수 있는 시간 형식으로 바꾸고, 시간 순서대로 정렬했어요.
3. **기록 간격**을 새로 계산했어요.
   - 기록 간격 = 같은 세션, 같은 리더기에서 **바로 앞 기록과 지금 기록 사이의 시간(초)**
4. 열마다 빈칸이 얼마나 있는지 확인했어요. 빈칸을 지우거나 채우지는 않았어요.

> 💡 `s5_plan.csv`는 마지막 칸(메모) 안에 쉼표가 들어 있어서 그냥 읽으면 칸이 밀려요. 그래서 넘치는 부분을 마지막 칸에 합쳐서 읽었어요.

## 2단계. 성공률 계산

실험마다 성공률을 구할 수 있는 자료가 달라서 아래처럼 계산했어요.

| 실험 | 계산 방법 |
|---|---|
| S1 | 요약 파일 `meta_sessions_S1.csv`의 성공률을 거리·각도별로 평균 |
| S2 | 요약 파일 `meta_sessions_S2.csv`의 성공률을 거리·각도별로 평균 |
| S3 | 전체 기록 중 `read_success`의 비율 |
| S4 | 전체 기록 중 `read_fail`이 **아닌** 기록의 비율 |
| S5 | 요약 파일 `s5_success_rates_per_session.csv`의 `success_rate_pct`를 계획표의 거리·각도와 연결해 평균. 이 값은 **리더기 B 기록 수 ÷ 리더기 A 기록 수**예요 |

## 3단계. 그래프 그리기

다섯 실험 모두 **같은 방법**으로 그렸고, 실험마다 색을 정해 두었어요.
(S1 파랑, S2 주황, S3 초록, S4 노랑, S5 분홍)

**다섯 실험 비교**

| 그래프 | 보여 주는 것 |
|---|---|
| 거리·각도별 성공률 | 다섯 실험의 성공률을 거리·각도별로 나란히 |
| 실험별 기록 간격 | 다섯 실험의 기록 간격을 상자그림으로 나란히 |

**실험마다 공통**

| 그래프 | 보여 주는 것 |
|---|---|
| 기록 간격 분포 | 기록 간격이 얼마일 때가 많은지 (히스토그램) |

**실험별 추가 그래프**

| 실험 | 그래프 | 보여 주는 것 |
|---|---|---|
| S1 | 카드별·리더기별 기록 수 | 어느 카드를 어느 리더기로 몇 번 읽었는지 |
| S2 | 두 리더기의 시각 차이 | 같은 카드를 A와 B가 읽은 시각이 얼마나 차이 나는지 |
| S3 | 두 리더기의 시각 차이 | 같은 번호의 카드가 두 리더기에 기록된 시각 차이 |
| S4 | 방식별 기록 종류 | 재전송 방식(복제 카드·휴대폰·프로그램)마다 성공·주입·실패 비율 |
| S4 | 재전송 지연 | 재전송 방식마다 지연 시간 분포 |
| S5 | 세션별 리더기 A · B 기록 수 | 36번의 실험 각각에서 두 리더기가 남긴 기록 수 |
| S5 | 세션별 B ÷ A 기록 수 비율 | 위 두 기록 수의 비율 (요약 파일의 `success_rate_pct`와 같은 값) |
| S5 | 시간에 따른 기록 수 | 한 세션 동안 1초마다 기록이 몇 개씩 생겼는지 |

> 💡 **그래프 읽는 법**
> - **히스토그램**: 값을 구간으로 나눠, 구간마다 몇 개인지 막대로 나타낸 그래프
> - **상자그림**: 상자는 가운데 50%의 값, 상자 안의 선은 중앙값
> - **로그 눈금**: 0.001, 0.01, 0.1, 1처럼 한 칸마다 10배씩 커지는 눈금. 아주 작은 값과 큰 값을 한 그래프에 담을 때 써요.

그래프마다 아래에 숫자 표(평균, 중앙값 등)도 함께 있어요.

## 직접 해 보기
